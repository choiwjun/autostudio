# RESEARCH — 블로그 글작성 프롬프트 개선 리서치 (2026-08-11)

> 방법: web-researcher 스킬 (DDG 검색 → 5개 출처 크롤링) · 수집일: 2026-08-11
> 질문: ① 네이버 블로그/애드포스트 검색·AEO 최신 기준 ② AI 검색 인용 구조 ③ 고수익 블로그 글 구조 패턴

## 1. 리서치 요약

2026년 검색 환경은 **'순위 경쟁'에서 'AI 인용 경쟁'으로 이동** 중.
- 네이버 AI 탭 2026-06-26 전면 출시, AI 브리핑 인용이 곧 노출 (연말까지 전체 질의 ~40% 확대 예정)
- AI 브리핑 인용 출처 1위 = **네이버 블로그 (158건)** — 이 프로젝트 채널이 최적 타깃
- 구글도 공식 가이드로 "AEO/GEO도 결국 SEO" 선언 — 기존 SEO 원칙 + 독창적 콘텐츠

## 2. 주요 발견 (출처 포함)

### 2.1 AI 브리핑 인용 7가지 조건 (옵티플로우, 2026-06)
1. **질문형 소제목 + 두괄식 답변** (첫 문단 핵심 답 2~3줄)
2. 메타데이터·본문 키워드 일치
3. 텍스트·Alt 중심 (이미지에 정보 묻지 않기)
4. **FAQ·경험·후기 포함** (신뢰 신호)
5. 스캔 가능한 구조 (리스트·표·단계) + 구조화 데이터
6. 엔티티·멀티채널 일관성
7. **최신성·출처 명시** (통계·수치에 출처·시점, 정기 갱신)
- 정보·정의형 질의에서 인용 활성, 상업형(추천·비교)은 제한 경향
- 네이버 경쟁력 콘텐츠 요소: 직접 경험·개인적 관점·문제 해결 과정·구체적 사례·진정성

### 2.2 C-Rank·AI 인용률 (TILNOTE, 2026-06)
- C-Rank = 주제 적합도·문서 신뢰도·출처 신뢰도 + 체류시간
- AI 인용에 유리한 콘텐츠: 구조화(H1-H3), 간결 문단, 질문-답변형, **데이터·통계 포함**, 공신력 있는 출처
- 제목 전략: 키워드+질문형, **연도·최신성 명시**, **핵심 요약 포함**("5가지 방법"), 클릭유도성보다 **정보성**

### 2.3 구글 공식 가이드 (Frostai 요약, 2026-05)
- RAG(그라운딩) + Query fan-out 위에서 기존 SEO 랭킹 사용 — **기본 SEO 그대로 유효**
- 콘텐츠 원칙: **독창적 관점**, **일반 상식 넘는(non-commodity) 콘텐츠**, 독자를 위한 구성, 고품질 이미지, 과최적화 금지
- "방문자가 즐겁고 유용하다고 느끼며 만족할 콘텐츠" — 제목이 약속한 걸 본문이 지키기

### 2.4 네이버 상위노출 글쓰기 구조 (블로랭크, 2026-06)
- 5단 구조: 제목(키워드 앞쪽) → 첫문단(핵심 답) → 소제목 본문 → **경험·사진** → 마무리(핵심 요약+다음 행동)
- 가장 흔한 실수: 제목-본문 불일치 (체류시간 급락 감지)
- 키워드는 자연스럽게 (과반복 역효과)

### 2.5 네이버 알고리즘 (어센트코리아)
- D.I.A.+ (딥 매칭·패턴 분석·동적 랭킹) — 검색 의도 매칭 우선
- VIEW 검색: **실제 경험 담은 콘텐츠 우대** (#리뷰 #내돈내산 #리얼추천)
- 스마트블록: 구체적·명확한 소재, 시의성 콘텐츠

## 3. 현재 프롬프트와의 갭 분석

| 영역 | 현재 (v23) | 리서치 기준 | 갭 |
|---|---|---|---|
| 두괄식 즉답 | ✅ 정보형 50~200자 즉답 | 첫문단 핵심 답 2~3줄 | ✅ 충족 |
| 질문형 소제목 | ✅ H2 질문형/정보형 | 질문형 소제목 | ✅ 충족 |
| FAQ | ✅ 필수 (검수) | FAQ = 신뢰 신호 | ✅ 충족 |
| 표·리스트·단계 | ✅ 표 검수, 단계 지시 | 스캔 가능 구조 | ✅ 충족 |
| 최신성 | ✅ temporal_relevance + 발행일 | 최신성·연도 | ✅ 충족 |
| 키워드 | ✅ 밀도 검수 | 과반복 금지, 자연스럽게 | ⚠️ 밀도 상한 3% 존재 — OK |
| **경험·후기** | ❌ 허위경험 검수로 1인칭 전면 금지 | 직접 경험·진정성 우대 (VIEW/AI) | ⚠️ AI 생성물의 구조적 한계 — **대안 지시 필요** |
| **출처 명시** | ⚠️ 수치 창작 금지만 (출처명 창작 지시 없음) | 출처·시점 명시, 공신력 출처 | ❌ **출처명 창작 금지 지시 부재** |
| **독창적 관점** | ❌ 일반 상식 나열 금지 지시 없음 | non-commodity | ❌ **정보형 템플릿에 부재** |
| 제목 | ✅ 키워드+30자 검수 | 연도 명시·정보성·핵심 요약 | ⚠️ **연도·정보성 지시 부재** |
| SYSTEM_PROMPT | ⚠️ "실제 경험 기반의 구체적 정보" | 진정성 vs 허위 창작 | ⚠️ **허위 경험 유발 표현** |

## 4. 개선 제안 (우선순위)

### P1 — 프롬프트 안전성 (높음)
1. **SYSTEM_PROMPT 수정**: "실제 경험 기반" → "**검증 가능한 구체적 정보·사례**" + "경험·출처·수치를 창작하지 말 것" 명시 — 현재 표현은 모델이 1인칭 경험을 지어내게 할 수 있고, 검수(허위경험 금지)와도 모순
2. **허위 출처 창작 금지**: "조사에 따르면", "OO 연구", "통계에 의하면" 등 출처·기관명 창작 금지 지시 (수치 창작 금지는 이미 있음)

### P2 — AI 인용·독창성 (높음)
3. **pass1/pass2에 AI 브리핑 인용 목적 명시**: "질문-답변·리스트·단계·표 구조가 AI 브리핑 인용에 유리" — 현재 구조 지시는 있으나 'AI 인용' 프레임 부재
4. **non-commodity 지시 (정보형 템플릿)**: "누구나 쓸 수 있는 일반 상식 나열 금지 — 구체적 기준·숫자·비교·함정 중심으로 독창적 관점"

### P3 — 제목·메타 (중간)
5. **제목 지시 보강**: 연도 명시 + 정보성(클릭베이트 금지) + 핵심 요약("N가지 방법") — tilnote 제목 전략 반영

### P4 — 범위 밖 (참고)
6. 이미지 Alt/스키마/엔티티 — 블로그 앱(autoblog) 영역 (JSON-LD 이미 구현됨)
7. 실제 경험 콘텐츠 — AI 생성 한계, 사용자 직접 경험 글은 별도 채널 권장
