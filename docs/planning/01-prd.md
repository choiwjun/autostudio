# 네이버 블로그 콘텐츠 자동화 제품 기획서

> 작성일: 2026-08-04 · 버전: v1 (socrates 기획 확정 반영)

## 1. 한 줄 요약

- **어떤 기능인지**: 대시보드의 키워드를 골라 "글 생성" 버튼을 누르면, 상위글 골격 분석을 바탕으로 블로그 초안(제목·첫문단·본문)과 블로그 이미지가 나오는 도구
- **누가 쓰는지**: 애드포스트 수익을 위해 네이버 블로그를 운영 중인 사람이, 키워드 대시보드에서 유망 키워드를 고른 뒤 글쓰기에 들어가기 전에 사용
- **한마디로 왜 필요한지**: "글쓰기 병목" — 매일 1편씩 쓰려 해도 제목부터 막히고, 써도 인용(조회수)이 안 되는 글만 나와서 시간이 아까움

## 2. 이번 버전에 들어가는 기능 (꼭 필요한 것)

### 기능 1: 글 초안 생성
- 뭘 하는 건지: 상위글 골격 분석 결과를 바탕으로 제목·첫문단·본문이 담긴 초안을 만든다
- 왜 필요한지: 글쓰기 병목을 없애기 위해 — 제목 고민부터 본문 구성까지 한 번에
- 첫 화면에 보이는지: 아니오 (대시보드 "글 생성" 버튼으로 진입)

### 기능 2: 제목·첫문단 생성
- 뭘 하는 건지: 질문형 소제목 + 첫 문단 즉답 구조로 제목과 첫문단을 만든다
- 왜 필요한지: 검색에서 인용(조회수)이 되는 글은 질문을 바로 답하는 구조라는 것이 데이터로 확인됨
- 첫 화면에 보이는지: 아니오 (초안 안에 포함)

### 기능 3: 블로그 이미지 생성
- 뭘 하는 건지: 글 주제에 맞는 블로그 대표 이미지를 AI로 생성해 초안에 넣어준다
- 왜 필요한지: "이미지만 인용"되는 글이 76%로 가장 높아, 이미지가 인용 전략의 절반을 차지하기 때문
- 첫 화면에 보이는지: 아니오 (초안 보기 화면에서 미리보기)

## 3. 누가 언제 쓰는지

- 블로그 발행 전, 대시보드에서 "오늘 쓸 키워드"를 고른 사람이 **글 생성 → 초안 검토 → 복사해서 네이버 블로그에 붙여넣기** 흐름으로 쓴다 (주 3~5회, 회당 10~15분)

## 4. 만들 때 조건

- 시간: 개인 프로젝트, 2주 내 MVP(첫 출시 버전 — 딱 핵심만) 목표
- 예산: 기존 인프라(Supabase/Vercel/GitHub Actions) + AI API 비용만 (무료 티어 기반)
- 혼자/팀: 혼자 (로컬 PC 없이 전부 클라우드에서 실행)

## 5. 이번 버전에서 빼는 것 (Won't)

- **블로그 발행 연동** — 빼는 이유: 초안을 사용자가 직접 검토·수정해야 품질이 나오므로, 자동 발행은 다음 버전에서 (반자동 방식)
- **FAQ/비교표 자동 추출** — 빼는 이유: 상위글 골격에서 뽑는 건 이번에, 완성된 FAQ/비교표 생성은 다음 단계
- **성과 추적(조회수/인용 체크)** — 빼는 이유: 글 자동 생성이 먼저고, 성과 측정은 글을 쌓은 뒤에 해야 의미 있음
- **초안 관리함(저장·목록·재편집)** — 빼는 이유: MVP(첫 출시 버전)에서는 생성→복사가 핵심이고, 관리함은 글이 쌓인 뒤 필요

## 6. 다시 정리한 한 줄 문제

- "블로그 글쓰기가 병목이라, 키워드를 찾아도 매일 1편씩 못 쓰고 있고, 써도 인용(조회수)이 안 되는 글만 나온다"
- 그래서 **상위글 골격을 분석해 초안을 자동 생성**하고, **이미지를 함께 만들어** 인용 확률을 높이는 데 집중한다
