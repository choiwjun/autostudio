## Must 기능과 연결

| Must 기능 | 어떤 결핍을 채우는지 |
|-----------|---------------------|
| 글 초안 생성 | 글쓰기 병목 — 제목부터 본문까지 한 번에 |
| 제목·첫문단 생성 | 인용 안 되는 품질 — 질문형 소제목 + 첫 문단 즉답으로 인용 구조 반영 |
| 블로그 이미지 생성 | 인용 확률 — "이미지만 인용" 76% 데이터 근거로 이미지를 함께 제공 |

## Won't 리스트와 그 이유

| Won't | 이유 |
|-------|------|
| 블로그 발행 연동 | 초안을 사용자가 검토해야 품질이 나옴 — 반자동이 먼저 |
| FAQ/비교표 자동 추출 | 상위글 골격에서 뽑는 게 이번, 완성형 생성은 다음 단계 |
| 성과 추적 | 글을 쌓은 뒤에 측정이 의미 있음 — 순서 문제 |
| 초안 관리함 | MVP(첫 출시 버전)에서는 생성→복사가 핵심 |

## 반복 등장한 핵심 가치

- "시간 절약" (글쓰기 병목 해소)
- "인용되는 글" (AI 인용 + 조회수 — 애드포스트 수익의 원천)
- "이미지의 중요성" (76% 데이터로 확인된 인용 전략)
