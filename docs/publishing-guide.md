# 블로그 발행 가이드 (D.I.A / C-Rank 대응)

> v8 (2026-08-05): 네이버 블로그 검색 알고리즘(C-Rank + D.I.A) 조사 결과 반영.
> 이 문서는 대시보드에서 생성한 **AI 초안을 발행하기 전**에 반드시 확인하는 체크리스트다.

## 배경: 네이버 블로그 검색은 두 알고리즘이 함께 작동한다

| 알고리즘 | 평가 대상 | 핵심 질문 | 변화 속도 |
|----------|-----------|-----------|-----------|
| **C-Rank** | 블로그 채널 전체 | "이 블로거가 믿을 만한가?" (출처 신뢰도·주제 전문성) | 느림 (수개월~1년 누적) |
| **D.I.A** | 개별 문서 | "이 글이 검색 의도에 부합하는가?" (문서 품질) | 빠름 (발행 후 수일~수주) |

**두 점수가 모두 높아야 상위 노출된다.** C-Rank는 단기간에 올릴 수 없고, 채널 단위의 꾸준한 주제 집중·활동이 필요하다. D.I.A는 개별 글 하나만 잘 써도 반영된다.

**중요**: AI 완전 자동 생성으로 의심되는 콘텐츠는 D.I.A에서 불이익을 받는다. 반자동 흐름(초안 → 사용자 검토·수정 → 발행)이 반드시 필요하다.

---

## 1. 발행 전 체크리스트 (글마다)

초안을 발행하기 전에 다음 항목을 확인하고 수정한다:

- [ ] **실사용 경험 보강**: "직접 써봤다"는 경험·상황·조건을 추가했는가? (AI 초안은 경험 톤이지만 실제 경험이 아니므로, 사용자가 실제 경험을 덧붙여야 함)
- [ ] **사진/이미지 보강**: 인터넷 다운로드 이미지는 D.I.A가 감지한다. **직접 촬영/제작한 원본 이미지** 최소 3~5장 포함
- [ ] **수치·근거 구체화**: 가격, 기간, 단계, 비교 데이터가 구체적인가? (막연한 설명 금지)
- [ ] **키워드 자연 배치**: 제목 1회 + 본문 자연스럽게 3~5회. 키워드 도배/반복은 어뷰징으로 판정
- [ ] **독창성**: 상위글과 유사한 표현이 없는가? 자신만의 기준·해석·팁 추가
- [ ] **제목-본문 일관성**: 제목이 약속한 내용을 본문이 실제로 담는가? (낚시성 제목 금지)
- [ ] **대가성 표시**: 협찬/광고 수익 글이면 "이 글은 업체로부터 원고료를 지원받아 작성되었습니다" 명시 (애드포스트 자동 표시 확인)

## 2. 채널(C-Rank) 관리 체크리스트 (지속)

- [ ] **주제 집중**: 카테고리를 1~3개로 유지. 잡탕 블로그는 C-Rank 감점
- [ ] **꾸준한 발행**: 주 2~4회 규칙적 발행 (최소 3~6개월 유지). 몰아쓰기보다 규칙성이 중요
- [ ] **저품질 글 정리**: 과거 복사·짧은 글·광고성 글은 비공개/삭제 (C-Rank는 전체 평균 품질 반영)
- [ ] **이웃 소통**: 댓글·공감·이웃 활동이 Chain(연쇄 반응) 신호로 작용
- [ ] **업데이트**: 발행 후 방치하지 말고, 오래된 글은 주기적으로 최신 정보로 갱신 (내구성 신호)

## 4. AEO (답변엔진 최적화) — AI 인용 대응

> 네이버 AI 브리핑(2025.3~)이 현행 AI 답변 서비스 (Cue는 2025.4 종료).
> AI 브리핑은 **블로그·카페 UGC를 우선 인용**하므로, 네이버 블로그가 구조적으로 유리하다.
> 초안 생성기가 FAQ 섹션·구조화 표·직접 답변을 자동 생성하지만, 발행 전 아래 항목을 확인한다.

**발행 전 AEO 체크리스트:**
- [ ] **첫문단 직접 답변**: 50~200자 안에 완결된 답이 있는가? (AI가 통째로 인용할 수 있는 구조)
- [ ] **FAQ 섹션**: "## 자주 묻는 질문" 3~5개 — 실제 검색어 형태 질문 + 답변 40~120자?
- [ ] **질문형 H2**: 소제목이 "~이란?", "~하는 방법", "~와 차이" 형태인가?
- [ ] **구조화 표/리스트**: 비교·수치가 줄글 대신 표/리스트로 표현됐는가? (AI가 인용 청크로 선호)
- [ ] **용어 정의**: 처음 나오는 전문 용어에 "~이란 ...이다" 정의가 있는가?
- [ ] **단정형 문장**: "~할 수도 있습니다" 대신 "~입니다"로 명확하게 (근거 수치 병기)

**AI 인용 확인 방법:**
- 네이버 검색에서 키워드 검색 → AI 브리핑에 출처 표시되는지 확인
- ChatGPT·Perplexity에 관련 질문 → 답변 하단 출처에 노출되는지 확인
- 모니터링은 수동이 현실적 (자동화 도구 초기 단계)

## 5. 분야별 전략 참고

- **정보형 키워드** (방법/비교/추천): 정리형·가이드형 구조가 유리 — 현재 초안 구조(질문형 소제목 + 즉답 첫문단)와 정합
- **구매 키워드**: 쇼핑·브랜드 공식 정보와 경쟁하므로 후기·실사용 중심으로 차별화
- **시의성 키워드**: 최신순 노출을 노려 단기 트래픽 확보 가능 (이슈성 키워드)
- **롱테일 키워드** (3단어+): 검색량 적어도 전환율 높고 C-Rank 축적에 유리

## 6. 도구

- 네이버 서치어드바이저: 검색 유입·클릭률·노출 키워드 모니터링
- 블로그 통계: 체류시간·재방문율·검색 유입 분석
- C-Rank 점수는 공식 비공개 — 외부 사이트(BLEX 등)의 점수는 **추정치**로만 참고
