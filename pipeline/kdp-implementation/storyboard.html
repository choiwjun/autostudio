1.1 탭 배치 (기존 v18 탭 패턴 확장)

기존 대시보드는 최상단 .tabs(키워드 목록 / 게시 플래너 / 수익 인사이트)를 가진다. KDP 파이프라인 구현을 위해 "KDP 출간" 탭 1개를 최상단 탭에 추가하고, 탭 내부는 기존 .seg 세그먼트 컨트롤로 4개 하위 화면(책 목록 · 출간 큐 · 48h 모니터링 · 성과 입력)을 전환한다.
