## 1. 화면 구성 요약

### 1.1 탭 배치 (기존 v18 탭 패턴 확장)

기존 대시보드는 최상단 `.tabs`(키워드 목록 / 게시 플래너 / 수익 인사이트)를 가진다. KDP 파이프라인 구현을 위해 **"KDP 출간" 탭 1개를 최상단 탭에 추가**하고, 탭 내부는 기존 `.seg` 세그먼트 컨트롤로 4개 하위 화면(책 목록 · 출간 큐 · 48h 모니터링 · 성과 입력)을 전환한다.

```
┌─────────────────────────────────────────────────────────────────────┐
│ (최상단 .tabs — 기존 3개 + 신규 1개)                                │
│  [ 키워드 목록 ]  [ 게시 플래너 ]  [ 수익 인사이트 ]  [ KDP 출간 ] ← 신규 (class="on") │
└─────────────────────────────────────────────────────────────────────┘
        │  tabKdp (.tabpane)
        ▼
┌─────────────────────────────────────────────────────────────────────┐
│  KDP 출간 패널 (card)                                              │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ (.seg 세그먼트 — KDP 내부 하위 탭)                             │ │
│  │ [ 책 목록 ] [ 출간 큐 ] [ 48h 모니터링 ] [ 성과 입력 ]           │ │
│  └───────────────────────────────────────────────────────────────┘ │
│  ┌───────────────────────────────────────────────────────────────┐ │
│  │ 하위 탭에 따른 화면(A·B·C·D) → 이하 §2~§5                       │ │
│  └───────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────────┘
```

> 상단 `#status`·**KPI 카드**(§1.2)는 `tabKdp` 아래 고정 재사용.

### 1.2 KPI 카드 (기존 `.kpis`/`.kpi` 구조 재사용 — 책 목록 상단)

```
┌──────────────┬──────────────┬──────────────┬──────────────┐
│ .kpi          │ .kpi          │ .kpi          │ .kpi          │
│ KDP 책        │ ready / 출간대기│ 오늘 출간      │ 48h 미검증     │
│ 6권           │ 4권           │ 2 / 3권        │ 1권            │
│ draft~monitoring│ (게이트: 3권)│ (진행 중)      │ (경고: .warn)  │
└──────────────┴──────────────┴──────────────┴──────────────┘

| status | 배지 클래스 | 라벨 | 시각적 신호 |
|---|---|---|---|
| draft | `.badge.b-gray` | draft | 중립 (생성 시작 전) |

- **EPUB 버튼**: `.btn.btn-sm.btn-gen`. `ready / published / monitoring`에서만 활성, `draft / assembling`은 `.btn:disabled` (K-3).
- **QC 리포트**: `.btn.btn-sm` "리포트" (`ready` 이상). 클릭 → `#detail` 모달 재사용, §2.2 QC 결과표 렌더.
- **생성일**: `created_at` (yyyy-mm-dd).

```

- **미검증 강조**(AC-K4-2·48h): `status=published & verified_at=NULL` 책을 목록 **상단 정렬** + `.badge.b-warn`("검증 대기") + 행 테두리 강조. 48h 경과 시 `#status.warn` + `[재확인 알림]` 배너.
- **가격·미러 이상 경고**(AC-K4-2③): 해당 셀 `.no`/`.warn-txt`로 "이상" 표시 + 우측 `[재확인 알림]`. 비정상 책은 verified 되어도 경고 신호 유지.

### 4.2 48h 확인 다이얼로그 → verified 저장

```
┌────────────────────────────────────────────────────────────┐
│  48h 확인 — "부자 되는 데일리 루틴"                   [✕]    │
├────────────────────────────────────────────────────────────┤
│  출간 후 Amazon에서 아래 3가지를 확인하세요.                  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │ ✓ 책 상태 (소장/구매 가능)                             │  │
│  │ ✓ 가격 ($9.99 — 정상)                                 │  │
│  │ ✓ 미러 (Kindle에서 정상 표시)                          │  │
│  └──────────────────────────────────────────────────────┘  │
│  [검증 완료 저장]  [뒤로]                                    │
│      → kdp_publish.status = verified, verified_at 기록,      │
│        미러 확인값은 kdp_publish.mirror_status(정상/이상)에 저장 │
└────────────────────────────────────────────────────────────┘
```
- **verified 저장**(AC-K4-2②): `[검증 완료 저장]` = `kdp_publish.status → verified` + `verified_at` 기록. 미러 확인값은 `kdp_publish.mirror_status`(정상/이상)에 함께 저장(QA-D6)하여 이후 재확인·경고 추적의 근거로 삼는다. 이후 행은 목록에서 빠지고 배지 `[verified]`(`.b-green`) 표시.

## 6. 공통 상태 정의 (전 화면)

### 6.1 빈 상태 (데이터 없음) — `.empty`

| 48h 모니터링 (0건) | "검증 대기 책이 없습니다 — 출간 48시간 후 여기에 표시됩니다" | — |

### 6.2 로딩 상태

- **책 목록·출간 큐·모니터링**: 기존 `.skel`(스켈레톤) 8행 렌더 — `.skel td` 애니메이션 재사용.
- **상세 모달/체크리스트 저장**: `.btn:disabled` + `.spinner`(`#34d399`).
- **책 생성/검수/재생성**: `.steps` + `.step.active`(blink)/`.step.done` — 기존 v8 패턴.

### 6.3 오류 상태

| 유형 | 표시 | CTA |
|---|---|---|
| API 401 | `#status.warn`: "토큰이 올바르지 않습니다" | 토큰 재설정 |
| 리스트 로드 실패 | `.empty` "데이터를 불러오지 못했습니다" | [다시 시도] |

### 6.4 게이트 차단 (AC-K4-1) — §3.3 통합

- **일 3권 초과**: 초과분만 `pending`(`.b-gray`) 배지 + "내일 자동 허용" 안내.
- **체크리스트 미완료**: 해당 행 `[출간 시작]` `.btn:disabled` + 행의 `.no` 사유 + 상단 `#status.warn` 차단 배너.

### 6.5 48h 미확인 강조 (AC-K4-2) — §4.1 통합

- 미검증(`status=published & verified_at=NULL`): 목록 상단 정렬 + `.badge.b-warn` "검증 대기".
- 48h 경과 미검증: 배지/행 테두리 강조(`var(--border-strong)` 기반 테두리 inline style 또는 기존 활성 경계) + 상단 `[재확인 알림]` 배너(`#status.warn`).
- 가격/미러 이상: 해당 셀 `.no`/`.warn-txt` + `[재확인 알림]`.

## 7. 재사용 vs 신규 요약 (기존 대시보드 정합성)

| 컴포넌트 | 기존 index.html 재사용 | KDP 확장 지점 |
|---|---|---|
| 탭/하위 탭 | `.tabs` + `.seg` | 최상단 탭 1개 추가, seg 4개 |
| 테이블 | `table`/`.mini-table`, 스티키 헤더 | 컬럼 정의(상태/진행률/QC/EPUB) |
| 배지 | `.badge` + b-gold/green/blue/warn/gray | 상태 5종 매핑(§2.1) — 신규 색 없음 |
| 진행률 바 | `.gauge` + g-blue/g-green | 챕터 진행률(수치 병기) |
| 카드/패널 | `.card`/`.panel-card`/`.kpi`/`.draft-block` | — |
| 버튼 | `.btn`/`.btn-primary`/`.btn-sm`/`.btn-gen` | EPUB/출간/저장 버튼 |
| 모달 | `#detail`/`#draftModal` .panel | 책 상세·체크리스트·48h 확인 |
| 상태 | `.skel`/`.empty`/`#status.warn`/`.no`/`.warn-txt` | §6 상태 정의 |
| 단계 | `.steps`/`.step.active/.done` | 출간 파이프라인 단계 표시 |

> 신규 컴포넌트(상태 배지 5종 매핑·챕터 진행률 바·업로드 체크리스트·48h 모니터링 리스트)는 전부 **기존 토큰/클래스를 조합** — 신규 팔레트·스타일 아님. 상세는 `design-system.md` §4.
