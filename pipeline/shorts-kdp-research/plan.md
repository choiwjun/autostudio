## 4. 기능 명세 (M/S/C — prd-writer 구조)

### F-1 쇼츠 수집·발굴 (Must — R-1)

**기능 설명**: YouTube Data API v3 기반 매일 1회 수집 → 원본 저장 → 주제 후보 판정.

**규칙/로직**:
- 데이터 소스: API v3 정식 (스크래핑/yt-dlp는 파일럿 보조·제한적, ToS 위반 리스크 명시)
- 쿼터 예산: 인기 50 + 채널 20 + 검색 10 + 댓글 20 ≈ **100 units/일 (10,000 대비 1%)**
- `search.list` 100회/일 별도 버킷 관리
- 판정 지표 (리서치 R-2 반영): ① 조회 급상승(24~48h) ② 공유율(공유/조회 ≥ 0.5%) ③ 조회/구독 비율 ④ 반응비(보조) ⑤ 틈새(경쟁도)
- **기술 복잡도: 중** (외부 API 연동 + 지표 계산 + 배치)

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-S1-1 | **Given** API 키가 `.env.local`에 설정됨 / **When** 매일 배치가 실행됨 / **Then** ① 인기 동영상(KR) 50개+ 검색 10회 수집 ② `youtube_raw`에 멱등 저장(video_id UNIQUE) ③ 쿼터 사용량 로그 기록 | • API 403/429: 지수 백오프 재시도, 실패 항목 로그 • 중복 video_id: UPSERT |
| AC-S1-2 | **Given** 수집 데이터 존재 / **When** 주제 판정 실행 / **Then** ① 소재 후보 10개+ 산출(점수순) ② 판정 근거(지표값·경쟁도) evidence JSON 저장 ③ 틈새 후보 표시 | • 데이터 부족(수집 0건): 판정 스킵 + 대시보드 경고 |
| AC-S1-3 | **Given** 후보 목록 / **When** 공유율·급상승 지표 산출 / **Then** 반응비는 보조 가중치로만 사용, 공유/조회 ≥ 0.5% 후보 우선 | • shareCount API 미제공 시: 조회급상승+반응비 대체(파일럿 검증) |
| AC-S1-4 | **Given** 일일 쿼터 예산 = 100 units (10,000 대비 1%) / **When** 배치가 예산 초과 위험 감지 / **Then** ① `search.list` 별도 버킷(100회/일) 초과분 스킵·로그 ② 전체 쿼터 10,000 초과 시 수집 중단·다음날 재시도 예약 ③ 대시보드에 쿼터 사용량·초과 경고 표시 | • 4xx(403/404) 오류: 재시도 금지(비용 낭비 방지) • 페이지네이션 추가 요청: 예산 내 1페이지만 |

### F-2 쇼츠 스크립트 생성 (Must — R-1)

**기능 설명**: 30~45초 스크립트(후킹 3초·CTA) 생성 + 검수 + edge-tts 음성.

**규칙/로직**:
- draft_pipeline 2패스 재활용 (플랫폼=shorts 포맷)
- 스크립트 길이: 30~45초 (한국어 80~120자) — 리서치 근거: 20~40초 가장 흔함, 상위권 완주율 80~90%
- 검수: 금지어·허위 주장·길이·후킹 존재
- TTS: **edge-tts 채택 (OQ-4)** — 자막 텍스트 병행 지원(수동 녹음)
- **기술 복잡도: 중** (LLM 호출 + 검수 규칙 + TTS)

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-S2-1 | **Given** 주제 후보 1건 / **When** 스크립트 생성 / **Then** ① 후킹 문장(첫 3초) 포함 ② 30~45초 분량 ③ CTA 포함 ④ 해시태그 3~5개 산출 | • 길이 초과: 재생성 지시 • 금지어 검출: 재생성 |
| AC-S2-2 | **Given** 스크립트 ready / **When** TTS 실행 / **Then** edge-tts 음성 파일 생성(성공 시), 실패 시 자막만 산출 | • TTS 실패: 자막 폴백, 대시보드 표시 |
| AC-S2-3 | **Given** 스크립트 완성 / **When** 대시보드 조회 / **Then** 스크립트·해시태그·참고영상·음성파일 다운로드 제공 | • 미검수 상태: draft 표시 |

### F-3 KDP 주제 선정·책 생성 (Must — R-2)

**기능 설명**: '곧 뜰' 키워드 → 영어 현지화·아마존 수요 검증 → 책 주제 → 아웃라인·챕터 생성 → QC 8항목 → EPUB 조립·검증.

**규칙/로직**:
- 키워드→주제 변환 (개선점 #4): 영어 현지화 + 아마존 검색 결과 스냅샷 검증 + 한국어 병행 옵션
- 챕터 6~12개, 일관성 보정 패스, 챕터당 하드 예산 300초
- QC 8항목 (개선점 #5): 표절 유사성·금지어·사실성·챕터 간 중복·길이(±20%)·AI 표기·마크다운 정합·메타데이터
- EPUB: ebooklib 조립 + calibre ebook-convert + epubcheck (GH Actions, 의존성 §2.1 — 개선점 #2)
- **기술 복잡도: 높음** (LLM 파이프라인 + EPUB 변환 + QC 규칙)

**수용 기준**:

| AC-K2-1 | **Given** 책 주제 확정 / **When** 책 생성 실행 / **Then** ① 아웃라인(6~12챕터) 생성 ② 챕터별 본문 생성(2패스) ③ 일관성 보정 패스 ④ 챕터당 예산 300초 초과 시 중단·재시도 | • 예산 초과: 부분 생성 상태 저장, 재개 |

**기능 설명**: 출간 큐(일 3권 게이트) + 수동 업로드 체크리스트 + 48h 모니터링.

**규칙/로직**:
- 일 3권 게이트 (14·12·11 공통 수치 — 정책 "둘 다 실존" 명시: 공식 주 10권 + 실질 일 3권)
- 출간 체크리스트: AI 표기·가격(70% 구간 $2.99~$12.99)·키워드 7개·카테고리 2개
- 48h 확인: 책 상태·가격·미러 — 대시보드 monitoring 상태
- **기술 복잡도: 낮~중**

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-K4-1 | **Given** ready 책 4권+ / **When** 출간 큐 확인 / **Then** ① 일 3권 초과분 pending 표시 ② 업로드 체크리스트 표시 ③ 수동 업로드 완료 후 status 전이 | • 3권 초과: 다음날 자동 허용 • 체크리스트 미완료: 게이트 차단 |
| AC-K4-2 | **Given** 출간 완료 / **When** 48h 경과 / **Then** ① 모니터링 리스트에 미검증 책 표시 ② 확인 완료 시 verified 저장 ③ 가격·미러 이상 시 경고 | • 48h 미확인: 대시보드 강조 • 가격 변동: 재확인 알림 |

### F-5 KDP↔쇼츠 시너지 (Should — R-3, 개선점 #8)

**기능 설명**: 책 챕터 → 쇼츠 대본 변환 → 아마존 링크 CTA.

**규칙/로직**:
- 챕터 핵심 팁 1개 = 30~45초 대본 (F-2 재사용)
- CTA: "Full chapter in my book on Amazon" + 아마존 상세페이지 링크
- 영어권 채널 전용 (OQ-5 채널 분리와 정합)
- **기술 복잡도: 중**

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-SY-1 | **Given** published 책 존재 / **When** 시너지 대본 생성 / **Then** ① 챕터 1개 → 대본 1개 생성 ② 아마존 링크 CTA 포함 ③ 책 메타(제목·링크) 대본에 삽입 | • 책 미출간: 생성 차단(링크 무효 방지) |
| AC-SY-2 | **Given** 시너지 대본 / **When** 채널 구분 / **Then** 영어권 채널 태그·설명 자동 구성 (한국어 운세 채널과 분리) | • 채널 미설정: 대시보드 경고 |
| AC-SY-3 | **Given** published 책 1권(챕터 6~12개) / **When** 시너지 흐름 실행 / **Then** ① 챕터 1개 → 대본 1개 → 아마존 링크 CTA까지 전체 흐름 완결 ② 대본에 책 제목·링크·CTA 문구 포함 ③ 생성 로그에 책→대본 매핑 기록 | • 챕터 0개(빈 책): 생성 차단 • 링크 무효(책 삭제·미러 전): 재확인 경고 |

### F-6 운세 카드 쇼츠 (Should — R-3)

**기능 설명**: 운세 엔진(결정적 계산) 기반 한국어 운세 카드 쇼츠 소재 생성.

**규칙/로직**:
- 엔진 데이터(60일주·별자리·띠) → 규칙 기반 결정적 생성 (LLM 0회 또는 최소) — "엔진=데이터, LLM=통역사" 원칙
- "오락·참고용" 프레이밍, 적중률 보장 표현 금지, 날짜만 입력(민감정보 미수집)
- 일일 갱신 = 업로드 리듬 확보 (파일럿 🥇)
- **기술 복잡도: 낮~중** (기존 engine 자산 재사용)

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-FT-1 | **Given** 운세 엔진 데이터 / **When** 카드 쇼츠 생성 / **Then** ① 띠·별자리 카드 문구 산출(결정적) ② 기준일 명시 ③ 금지어(보장/무조건) 검수 통과 | • 기준일 중복: 멱등 스킵 |
| AC-FT-2 | **Given** 카드 문구 / **When** 대시보드 표시 / **Then** 자막 텍스트 + (edge-tts) 음성 + 해시태그 제공 | • 엔진 데이터 없음: 생성 차단 |
| AC-FT-3 | **Given** 운세 카드 문구 ready / **When** 채널·리듬 관리 / **Then** ① 한국어 운세 채널 전용 태그·설명 구성(영어 KDP 채널과 분리 — OQ-5) ② 일일 갱신 리듬 목록(날짜별) 표시 ③ 같은 기준일 중복 생성 시 멱등 스킵 | • 채널 미설정: 대시보드 경고 • 리듬 중단(2일+ 미생성): 알림 |

### F-P 파일럿 게이트 (Should — R-5)

**기능 설명**: 파일럿 주제·우선순위 최종 확정 게이트 (OQ-2·OQ-3 결정을 실행 단계에서 확정).

**규칙/로직**:
- OQ-2(주제 비중 운세4+KDP3+일반3)·OQ-3(52주 워크북) 결정은 기획 단계의 방향 — **파일럿 실행 직전 K-1/S-2 결과로 최종 확정**
- 쇼츠 파일럿: 소재 후보 10개 → 선정 기준 5종(수요·자동화 궁합·수익 경로·리듬·차별화)으로 5개 쇼츠 확정
- KDP 파일럿: 52주 워크북 + 아마존 검색 스냅샷(상위 20권) 경쟁도 판정 통과 시 확정
- **기술 복잡도: 낮** (게이트 로직·체크리스트)

**수용 기준**:

| AC | Given / When / Then | Edge Case |
|---|---|---|
| AC-P1-1 | **Given** S-2 주제 판정 완료 (후보 10개+) / **When** 파일럿 게이트 실행 / **Then** ① 선정 기준 5종 스코어 산출 ② 상위 5개 쇼츠 확정·대시보드 표시 ③ OQ-2 비중(운세4+KDP3+일반3)과 대조해 조정 권고 | • 후보 < 10개: 수집 재실행 권고 • 기준 충돌(수익 경로 vs 리듬): 가중치 순위 명시 |
| AC-P1-2 | **Given** K-1 주제 선정 완료 (52주 워크북 후보) / **When** KDP 파일럿 게이트 실행 / **Then** ① 아마존 검색 스냅샷(상위 20권 가격·평점·권수) 판정 ② 경쟁도 통과 시 52주 워크북 확정·시리즈 후보(월/분기/연간) 표시 ③ 실패 시 대체 후보 재선정 | • 스냅샷 데이터 부재: 판정 보류·재실행 • 경쟁도 높음: 틈새 변형(니치 세분화) 권고 |
