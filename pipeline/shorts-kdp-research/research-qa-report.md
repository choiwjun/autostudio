## 1. 출처 유효성 — ✅ PASS

### 검증 방법
- 보고서 본문 + §9 출처 목록에서 인용 URL **53개 전부 추출**하여 직접 HTTP 요청
- HTTP 상태 코드·최종 리다이렉트 URL·콘텐츠 타입 확인
- 403(봇 차단) 응답은 crawled/ 원천 데이터(마크다운·검색 인덱스)로 존재성·내용 일치를 별도 확인

### 결과

| 구분 | 건수 | 상태 |
|---|---|---|
| HTTP 200 (정상 접속) | 49 | ✅ 전부 실제 존재 |
| HTTP 403 (봇 차단 — 콘텐츠는 crawled로 확인) | 4 | ✅ 존재 확인 (Medium 2, ISBNdb 1, GrandView 1) |
| 접속 불가/404 | 0 | — |

**403 4건 상세** (모두 크롤링 원본이 있어 내용 검증 완료):
- `medium.com/@antoinelacombled/...` — 33억 뷰 연구: crawled 마크다운 존재, 수치 일치 ✅
- `medium.com/the-kdp-files-steal-my-notes/...` — 100권×3/일=월 $2.5만: crawled에 **부재**, 접속도 403 → **미검증(참고치)** — 다만 보고서가 C등급(추정·커뮤니티)으로 명시해 정직성은 충족
- `isbndb.com/blog/...` — crawled 마크다운 존재, 수치 일치 ✅
- `grandviewresearch.com/...` — crawled 마크다운 존재, 수치 일치 ✅

**발견 문제 P1 (정보/경미)**: 레딧 URL 2건이 절단 표기됨
- `.../multiple_book` → 실제 `.../multiple_books_the/` (검색 인덱스로 존재 확인, 접속은 봇 차단)
- `.../shorts/?tl=` → 실제 `?tl=ko` (검색 인덱스 확인)
- 영향: URL 자체는 리다이렉트되어 동작하나, 출처 목록의 추적성(NFR-2) 관점에서 정확한 URL로 수정 권장

## 4. 주장-근거 연결 — ✅ PASS

- **핵심 주장 40+건 전부 인라인 출처 연결** (본문 각 수치에 링크 존재)
- **단일 출처 정보 표시**: 
  - "쇼츠 광고 점유율 22%" → "단일 출처, 신뢰도 ⚠️" 명시 ✅
  - "김프로 775억 뷰" → "⚠️ 2차 출처" 명시 ✅
  - "KDP 평균 판매량" → "레딧 보고" 명시 ✅
- **판단형 주장은 근거와 분리**: "일 3권 게이트 유지 타당"은 공식 Help(주 10권) + 가디언(일 3권) + 레딧 실측을 제시한 뒤 결론 도출 — 주장과 근거의 구분이 명확

**발견 문제 P3 (정보/경미)**: "12권 중 1권" 수치는 크롤링 스냅샷에는 없었으나, A2Z 라이브 페이지에서 "1 out of 12 printed books sold" 확인 → **해제** (문제 아님).
