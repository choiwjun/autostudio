쇼츠 + KDP 파이프라인 — 테스트 설계 (test-design.md)

작성: 기획팀 · 프로젝트: autostudio · 작성일: 2026-08-14 · 상위: plan.md(AC) · 모드: standard
방법: test-case-writer 스킬 — AC → 테스트 케이스 매핑 (정상·경계·예외)
용도: 개발팀 TDD 시작점 + 개발QA팀 검증 기준

테스트 우선순위 (핵심 플로우 → 엣지)

  1. P0 (필수): 수집 멱등·쿼터 예산(AC-S1-4)·책 생성·QC 8항목(AC-K2-1~2)·출간 게이트(일 3권)·EPUB 검증 — 정책/계정 리스크 직결
  2. P1 (중요): 주제 판정 지표·스크립트 검수·48h 모니터링·시너지 흐름(AC-SY-3)·운세 카드 리듬(AC-FT-3)·파일럿 게이트(AC-P1-1~2)
  3. P2 (보조): 대시보드 UI·성과 입력·운세 카드 멱등

AC → 테스트 케이스 매핑

F-1 쇼츠 수집·발굴 (AC-S1-1 ~ AC-S1-4) — P0/P1

TC AC 시나리오 예상 결과
T-S1-01 AC-S1-1 API 키 설정 후 배치 실행 → 인기 50+검색 10 수집 youtube_raw 60+ 행, 쿼터 로그 ~100 units
T-S1-02 AC-S1-1 같은 video_id 재수집 (2회차) 중복 0 (UPSERT)
T-S1-03 AC-S1-1 API 429 응답 (쿼터 초과) 지수 백오프 재시도 → 실패 로그, 다음날 리셋
T-S1-04 AC-S1-1 API 403 (키 무효) 재시도 금지 + 대시보드 경고 (4xx는 재시도 X)
T-S1-05 AC-S1-1 search.list 100회 초과 요청 별도 버킷 한도 적용 — 초과분 스킵 + 로그
T-S1-06 AC-S1-2 수집 데이터 정상 → 주제 판정 실행 후보 10개+ 점수순, evidence JSON 포함
T-S1-07 AC-S1-2 수집 0건 (배치 실패) 판정 스킵 + "수집 실패" 경고
T-S1-08 AC-S1-3 공유율 ≥ 0.5% 후보 vs 미만 후보 0.5%+ 후보 우선순위 상향
T-S1-09 AC-S1-3 shareCount API 미제공 (채널 비소유) 공유율 대체(조회급상승+반응비) 적용 — 파일럿 검증 플래그
T-S1-10 AC-S1-4 search.list 100회 초과 요청 별도 버킷 한도 적용 — 초과분 스킵 + 로그 (쿼터 예산 초과 처리)
T-S1-11 AC-S1-4 전체 쿼터 10,000 초과 위험 수집 중단 + 다음날 재시도 예약 + 대시보드 쿼터 경고
T-S1-12 AC-S1-4 4xx 오류 (403/404) 재시도 금지 (비용 낭비 방지) + 실패 로그

F-2 쇼츠 스크립트 (AC-S2-1 ~ AC-S2-3) — P1

TC AC 시나리오 예상 결과
T-S2-01 AC-S2-1 주제 후보 1건 → 스크립트 생성 후킹(3초)·30~45초·CTA·해시태그 3~5개 포함
T-S2-02 AC-S2-1 스크립트 길이 초과 (>45초 분량) 재생성 지시
T-S2-03 AC-S2-1 금지어 검출 (허위 주장·과장) 재생성 + 사유 로그
T-S2-04 AC-S2-2 edge-tts 정상 실행 음성 파일 생성
T-S2-05 AC-S2-2 edge-tts 실패 (네트워크 등) 자막 폴백 + 대시보드 표시
T-S2-06 AC-S2-3 스크립트 ready → 대시보드 조회 복사·다운로드(음성) 제공, draft는 미표시

F-3 KDP 주제·책·EPUB (AC-K1-1 ~ AC-K3-1) — P0/P1

TC AC 시나리오 예상 결과
T-K1-01 AC-K1-1 '곧 뜰' 키워드 10개 → 주제 선정 영어 현지화 키워드 + 스냅샷(상위 20권) + 틈새 판정 + 후보 목록
T-K1-02 AC-K1-1 아마존 검색 결과 0건 수요 미검증 → 후보 제외
T-K1-03 AC-K1-1 영어 현지화 불가 키워드 한국어 병행 옵션 플래그 표시
T-K2-01 AC-K2-1 책 주제 확정 → 책 생성 아웃라인 6~12챕터 + 본문 + 일관성 패스 완료
T-K2-02 AC-K2-1 챕터 예산 300초 초과 부분 생성 상태 저장 → 재개 가능
T-K2-03 AC-K2-2 QC 8항목 전부 통과 status=ready
T-K2-04 AC-K2-2 챕터 간 중복 ≥ 0.8 (임베딩) 재작성 지시 + 리포트
T-K2-05 AC-K2-2 AI-generated 판정 (LLM 초안) 출간 공개 문구 필수 표기
T-K2-06 AC-K2-2 AI-assisted 판정 (직접 작성+AI 편집) 공개 불필요 표기 (판정 근거 로그)
T-K3-01 AC-K3-1 QC 통과 → EPUB 조립 ebooklib EPUB 생성
T-K3-02 AC-K3-1 calibre ebook-convert 에러·경고 0 (GH Actions)
T-K3-03 AC-K3-1 epubcheck 실행 오류 0
T-K3-04 AC-K3-1 변환 경고 발생 원인 로그 + 재생성 지시

F-4 출간 큐·모니터링 (AC-K4-1 ~ AC-K4-2) — P0

TC AC 시나리오 예상 결과
T-K4-01 AC-K4-1 ready 책 4권 → 출간 큐 3권만 통과, 1권 pending
T-K4-02 AC-K4-1 체크리스트 미완료 (AI 표기 미확인) 게이트 차단
T-K4-03 AC-K4-1 3권 초과분 → 다음날 배치 자동 허용 (일 3권 리셋)
T-K4-04 AC-K4-2 출간 후 48h 경과 미검증 책 monitoring 강조
T-K4-05 AC-K4-2 확인 완료 status=verified, verified_at 기록
T-K4-06 AC-K4-2 가격·미러 이상 발견 경고 + 재확인 알림

F-5 시너지 (AC-SY-1 ~ AC-SY-3) — P1

TC AC 시나리오 예상 결과
T-SY-01 AC-SY-1 published 책 → 시너지 대본 챕터 1개→대본 1개, CTA+아마존 링크 포함
T-SY-02 AC-SY-1 미출간 책 → 시너지 요청 생성 차단 (링크 무효 방지)
T-SY-03 AC-SY-2 영어권 채널 미설정 대시보드 경고 (채널 분리 확인)
T-SY-04 AC-SY-3 published 책 1권(챕터 6~12개) → 시너지 흐름 챕터→대본→아마존 링크 CTA 전체 완결, 책→대본 매핑 로그 기록
T-SY-05 AC-SY-3 챕터 0개 (빈 책) 생성 차단
T-SY-06 AC-SY-3 책 삭제·미러 전 (링크 무효) 재확인 경고 + 링크 검증

F-6 운세 카드 (AC-FT-1 ~ AC-FT-3) — P1/P2

TC AC 시나리오 예상 결과
T-FT-01 AC-FT-1 엔진 데이터 정상 → 카드 생성 결정적 문구(LLM 0회) + 기준일 명시
T-FT-02 AC-FT-1 금지어(보장/무조건) 포함 생성 차단 + 사유
T-FT-03 AC-FT-1 같은 기준일 재실행 멱등 스킵
T-FT-04 AC-FT-2 대시보드 운세 필터 자막+음성+해시태그 제공
T-FT-05 AC-FT-2 엔진 데이터 없음 생성 차단
T-FT-06 AC-FT-3 운세 카드 ready → 채널·리듬 관리 한국어 운세 채널 태그·설명 구성, 일일 리듬 목록 표시
T-FT-07 AC-FT-3 같은 기준일 재실행 멱등 스킵 (중복 생성 방지)
T-FT-08 AC-FT-3 2일+ 리듬 중단 알림 발생 (업로드 리듬 유지)
