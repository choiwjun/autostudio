# 쇼츠 + KDP 파이프라인 — 테스트 설계 (test-design.md)

> 작성: 기획팀 · 프로젝트: autostudio · 작성일: 2026-08-14 · 상위: `plan.md`(AC) · 모드: standard
> 방법: test-case-writer 스킬 — AC → 테스트 케이스 매핑 (정상·경계·예외)
> 용도: 개발팀 TDD 시작점 + 개발QA팀 검증 기준

## 테스트 우선순위 (핵심 플로우 → 엣지)

1. **P0 (필수)**: 수집 멱등·쿼터 예산(AC-S1-4)·책 생성·QC 8항목(AC-K2-1~2)·출간 게이트(일 3권)·EPUB 검증 — 정책/계정 리스크 직결
2. **P1 (중요)**: 주제 판정 지표·스크립트 검수·48h 모니터링·시너지 흐름(AC-SY-3)·운세 카드 리듬(AC-FT-3)·파일럿 게이트(AC-P1-1~2)
3. **P2 (보조)**: 대시보드 UI·성과 입력·운세 카드 멱등
