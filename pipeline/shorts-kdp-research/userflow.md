# 쇼츠 + KDP 파이프라인 — 사용자 흐름 (userflow.md)

> 작성: 기획팀 · 프로젝트: autostudio · 작성일: 2026-08-14 · 상위: `plan.md`(F-1~F-7)
> 용도: 디자인팀 인계용 (스토리보드의 뼈대) · 흐름 5개: 쇼츠 발굴·KDP 생성·출간·시너지·운세 카드

## 여정 1: 쇼츠 소재 발굴 → 제작 (운영자, 매일)

```
[시작] 운영자 로그인 (대시보드)
  → [S-1] 매일 배치 수집 (유튜브 API v3, ≈100 units) — 자동
  → [S-2] 주제 판정: 조회급상승·공유율·조회/구독·틈새 → 소재 후보 10개+ (점수순)
  → [S-3] 스크립트 생성 (30~45초·후킹·CTA) + edge-tts 음성(선택) + 해시태그
  → [대시보드] 소재 목록 확인 (점수·근거 evidence)
  → 운영자: 후보 선택 → 스크립트 복사 → 영상 편집(Shotcut/CapCut) → 수동 업로드
  → [성과 입력] 조회·구독(API)·완주율·수익(Studio — 채널 소유 시) 수동 기록 → 시리즈화 판단 (S-2)
[종료] 다음날 배치로 갱신
```

**화면 매핑**: 대시보드 소재 탭(목록·상세·복사) · 성과 탭(입력 폼) — autostudio 기존 탭 패턴
**예외·이탈 지점**:
- API 403/429: 배치 재시도, 대시보드 경고 배너
- 소재 0건 (수집 실패): "수집 실패" 안내 + 재실행 버튼
- 완주율·공유수는 API 미제공: 채널 소유 시에만 Studio 데이터 참고 (S-2)

## 여정 2: KDP 책 생성 (운영자, 1권당 여러 날)

```
[시작] '곧 뜰' 키워드 프리셋 (기존 자산)
  → [K-1] 영어 현지화 + 아마존 검색 스냅샷 (상위 20권) → 틈새 판정 → 책 주제 후보
  → 운영자: 후보 승인 — 영어/한국어 양쪽 후보, 전환율 30% 미만 시 KDP KR 병행 (K-2)
  → [K-2] 아웃라인(6~12챕터) → 챕터 생성(2패스+일관성) → QC 8항목 (AI 표기 포함)
  → [K-3] EPUB 조립 (ebooklib) + calibre/epubcheck 검증 (GH Actions)
  → [대시보드] 책 목록: 상태 배지(draft→assembling→ready) + EPUB 다운로드
  → 운영자: Kindle Previewer 최종 확인 (선택)
[종료] ready 상태 → 출간 큐 대기
```

**화면 매핑**: KDP 탭(책 목록·챕터 진행률 바·EPUB 다운로드·QC 리포트)
**예외·이탈 지점**:
- 검색 결과 0건: 수요 미검증 → 후보 제외 (재선정)
- 챕터 예산 초과(300초): 부분 생성 상태 저장, 다음 배치에서 재개
- QC 실패 항목: 항목별 리포트 → 재생성 지시

## 여정 3: KDP 출간 + 48h 모니터링 (운영자, 수동)

```
[시작] ready 책 선택 (출간 큐 — 일 3권 게이트)
  → 체크리스트 확인: AI 표기(필수)·가격(70% 구간)·키워드 7개·카테고리 2개
  → 3권 초과분: pending (다음날 허용)
  → 운영자: KDP 웹 수동 업로드 (EPUB 다운로드 → 아마존 KDP)
  → status: published
  → [48h 경과] 모니터링 리스트: 책 상태·가격·미러 확인 → verified
  → 가격·미러 이상: 경고 + 재확인 알림
[종료] 성과 입력 (판매·로열티) → 대시보드 집계
```

**화면 매핑**: KDP 탭 출간 체크리스트 + 모니터링 리스트 (monitoring 배지)
**예외·이탈 지점**:
- 48h 미확인: 리스트 상단 강조
- 체크리스트 미완료: 게이트 차단 (일 3권 무관)

## 여정 4: KDP ↔ 쇼츠 시너지 (영어권 — F-5)

```
[시작] published 책 1권 선택
  → 챕터 1개 → 쇼츠 대본 1개 (30~45초, CTA "Full chapter in my book on Amazon")
  → 아마존 상세페이지 링크 삽입 (책 메타)
  → 영어권 채널 태그·설명 자동 구성 (채널 분리 — OQ-5)
  → [대시보드] 시너지 대본 목록 (책 연동 표시)
  → 운영자: 영상 제작 → 영어권 채널 수동 업로드
  → 시청자: 쇼츠 → 아마존 링크 클릭 → 책 구매 → 리뷰 → 다음 쇼츠 소재 (선순환)
[종료] 성과: 아마존 유입·판매 추적 (수동 입력)
```

**화면 매핑**: 소재 탭(시너지 대본) + KDP 탭(책 링크)
**예외·이탈 지점**:
- 책 미출간: 생성 차단 (링크 무효 방지)
- 채널 미설정: 대시보드 경고

## 여정 5: 운세 카드 쇼츠 (한국어 — F-6)

```
[시작] 운세 엔진 데이터 (60일주·별자리·띠 — 결정적 계산)
  → 카드 문구 생성 (규칙 기반, 금지어 검수, "오락·참고용" 프레이밍)
  → 기준일 명시 (중복 시 멱등 스킵)
  → 자막 텍스트 + edge-tts 음성(선택 — 파일럿 전 라이선스 검증, S-4) + 해시태그
  → [대시보드] 운세 카드 쇼츠 목록 (일일 갱신)
  → 운영자: 영상 제작 → 한국어 운세 채널 수동 업로드 (일일 리듬)
  → 시청자: 카드 시청 → (B2C 웹 후) myeong.kr 리포트 CTA
[종료] 성과 입력 → 주간 리듬 평가
```

**화면 매핑**: 소재 탭(운세 카드 필터) — 11-fortune §8-1 프롬프트 A(SNS 카드) 구조 재사용
**예외·이탈 지점**:
- 엔진 데이터 없음: 생성 차단 (LLM 환상 콘텐츠 금지)
- 기준일 중복: 멱등 스킵 (재발행 방지)
